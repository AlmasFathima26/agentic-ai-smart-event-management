# EventOps AI – Smart Event Management

## About
EventOps AI is a Flask-based web application designed to simplify event registration, coordination, and management.

## Technologies Used
- Python
- Flask
- HTML and CSS
- Bootstrap
- SQLite

## Features
- User registration and login
- Browse and register for events
- Event management dashboard
- Event feedback system
